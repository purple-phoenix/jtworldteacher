# JT McCarthy X Catalog

Research catalog of posts and Spaces from **[@McCarthy_JT](https://x.com/McCarthy_JT)**. Internal context for the `jtworldteacher` project (the public-facing site lives in `../site/`; the publishable podcast workflow is in `../PODCAST.md`).

Source: manual screenshots from X (X blocks scraping), and `yt-dlp` for Space audio.

## Structure

- `posts/` — one markdown file per post, `YYYY-MM-DD-short-slug.md`. Each file has YAML frontmatter (date, type, engagement, topics) plus the tweet text, media transcription, and analysis notes.
- `media/` — screenshots and embedded images, named to match the post slug.
- `spaces/audio/` — Space recordings as `.m4a` (git-ignored — large binary files).
- `spaces/transcripts/` — whisper-cpp transcripts of Spaces. Tracked in git.
- `WORKFLOW.md` — how to add new posts and Spaces to this catalog.

## Recurring themes

- **Technical Remote Viewing (TRV)** — core topic; Ed Dames lineage, Stargate-adjacent.
- **Mundane / Vedic astrology** — applied to current events (Iran, oil, "Astro RV" segments).
- **Critique of online UFOlogy ("UFOx")** — frames existing community as dysfunctional, captured ("psyop"), karmically bankrupt.
- **"Against the Archons" / "Dungeoncore"** — Gnostic-flavored framing of reality as a contested overlay; ancient civs (East Asia, Hindu vimanas) as actors.
- **AI as Jungian shadow / "summoning aliens"** — joins his AI / "context engineering" interest with his psychological frame.
- **Eastern Orthodox Christianity** — quietly load-bearing under all of it.
- **X Spaces** — primary live medium; recurring weekly slots (Thu, Fri, Sat evenings).
